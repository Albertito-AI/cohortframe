# Distribution and provenance

CohortFrame 0.1 is an original development prototype prepared for Albert Tan's Atlas Agent School community project. Its implementation is not a copy or fork of OpenFilm source. The proposal was informed by a source review of that project.

No public open-source licence has been selected for this initial private development package. The package is supplied for the founder's evaluation and authorised project development. Rights and contribution terms for a later public release must be recorded explicitly.

FFmpeg and ffprobe are separate required executables. They are not bundled in this source package, and their licences and build configurations apply independently. Obtain them from a trusted source: https://ffmpeg.org/download.html.

The demonstration audio is generated by the included original procedural fixture. It is not a Suno, InsMelo or other model-generated recording. Example text and graphics are project-authored. No paid provider integration or commercial music-rights guarantee is included.
