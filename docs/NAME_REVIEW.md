# CohortFrame: preliminary name review

**Review date:** 28 October 2026. **Decision:** retain CohortFrame as the working name for the private v0.1 project.

## Public checks performed

Public web searches for `"CohortFrame"`, the lowercase spelling, and software-related variants surfaced no exact-name product in the results reviewed. A separate exact-name search, including npm and PyPI domains, returned no results. Search indexes are incomplete and this does not prove that no other use exists.

The following primary endpoints were then checked directly, read-only:

| Check | Observed response |
| --- | --- |
| [GitHub public repository search](https://api.github.com/search/repositories?q=cohortframe&per_page=10) | HTTP 200; `total_count: 0`; `incomplete_results: false`. |
| [npm exact package endpoint](https://registry.npmjs.org/cohortframe) | HTTP 404; `{"error":"Not found"}`. |
| [PyPI exact project endpoint](https://pypi.org/pypi/cohortframe/json) | HTTP 404; `{"message":"Not Found"}`. |

These responses describe the lookup results at the review time. They do not reserve a name or establish that a registry will allow its registration.

## Nearby naming

[Chapterframe](https://chapterframe.ai/) describes an AI production studio for film on its own website. It is a different name in a related category. This screen found no exact collision strong enough to justify changing the working name, but the shared creative use of “frame” should be considered when preparing a public brand.

“Cohort” connects the project to continuity across Atlas cohorts. Outside that context it may suggest education, so use a descriptive subtitle: **Local video rendering for agent workflows.** Do not shorten the name to another existing brand or imply an official OpenFilm edition.

## Scope and next decision

This is a preliminary public name screen, not trademark or legal clearance. Trademark registers, company registers, domain ownership/availability, social handles, and non-indexed or private uses were not comprehensively checked. No domain, account, package, or trademark was registered as part of this review.

Before committing to standalone public branding, repeat the relevant checks, decide target markets, and assess any necessary jurisdiction-specific clearance. The current decision permits a reversible working name for private implementation; it is not a finding of exclusive rights.
