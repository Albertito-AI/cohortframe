    03 / YOUR MACHINE. YOUR WORKFLOW.

    Take it from here.

    Download the evaluation package, install it locally, and render your first brief. Python 3.11+ and a trusted FFmpeg build with libx264 and AAC are required.

    View project repository ↗Discuss an adaptation ↗

    Evaluation alpha. Tested on Linux. No hosted renderer, AI generation, billing or security certification. Source is available for inspection; no open-source licence is granted.

    LOCAL QUICK START
    python -m venv .venv
. .venv/bin/activate
python -m pip install .
cohortframe doctor
cohortframe validate cohortframe-project.json
cohortframe preview cohortframe-project.json --output frames
cohortframe project create cohortframe-project.json

    Then submit the returned project ID:
    cohortframe job submit PROJECT_ID --expected-revision 1 --key first-export --run

    Does this generate footage or music with AI?

    No. CohortFrame renders structured title cards locally using FFmpeg. You can supply a local PCM WAV soundtrack. It has no connected generation providers.

    Where does my work go?

    Edits are saved in this browser's local storage when available. Downloads stay on your device. The composer does not upload your brief or audio. Use “Clear saved draft” on shared devices. The hosting provider may receive ordinary page requests.

    Is this a complete video editor?

    This release focuses on repeatable title-card sequences, up to 12 scenes and 60 seconds. It does not edit footage or add transitions. The browser preview is illustrative; exact still previews and MP4 rendering run through the local CLI.

    Who is behind CohortFrame?

    CohortFrame is an Atlas Agent School community project under Albert Tan Sin Hon's stewardship. Future cohort participation is a plan. The current product does not claim an autonomous student workforce or customer deployments.
